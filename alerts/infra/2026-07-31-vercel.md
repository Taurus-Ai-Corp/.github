## Recommended Fix

**Short term — close or hold these Dependabot PRs:**
- PR #52 (`typescript` 7.0.2) — TypeScript 7 requires a migration; close and pin TypeScript to `~5.x` until a planned upgrade sprint.
- PR #53 (`@neondatabase/serverless` 1.1.0) — Review the v1 changelog for breaking changes before merging.
- PR #54 (`@noble/hashes` 2.2.0) — `@noble/post-quantum` must also be updated to a version compatible with `@noble/hashes` 2.x; do them together.
- PR #55 (`stripe` 22.x) — Stripe major bumps require API migration; scope the changes before merging.
- PR #48 (minor-and-patch group with `@taurus-ai/swarm-spawner` 0.4.0→0.5.1 and `drizzle-orm` 0.39.3→0.45.2) — `drizzle-orm` 0.45.x has schema API changes; review before merging.

**Long term:**
- Add Dependabot `ignore` rules for `major` version bumps on security-critical packages (`@noble/*`, `stripe`, `@neondatabase/*`) to prevent unreviewed major upgrades from auto-triggering.
- Consider splitting the minor-and-patch group PR into smaller focused PRs so individual failures are easier to diagnose.
