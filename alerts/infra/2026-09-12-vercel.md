The `main` branch production deploy also errored, meaning the **production deployment of `mater-maria` on Vercel is broken**.

**Root Cause:**

`mater-maria` is a **static site** built with vanilla HTML/CSS/JS and deployed via Wrangler (Cloudflare Pages). The Vercel project is incorrectly configured with Framework Preset = **Next.js**. Vercel's build detector looks for `next` in `package.json`, finds nothing, and hard-fails every deploy. This has been broken for at least 3 days with 24+ total failures recorded.

**Recommended Fix:**

This fix takes ~2 minutes in the Vercel dashboard — no code changes needed:

1. **Go to Vercel Dashboard → `mater-maria` Project Settings → General**
2. Under **Framework Preset**, change from `Next.js` → `Other` (or blank/static)
3. Set **Build Command** to the actual build command (e.g. `node scripts/build-pages.mjs` or leave blank if pre-built)
4. Set **Output Directory** to `platform` (based on commit messages referencing `wrangler pages deploy` from the `platform/` dir)
5. Save and redeploy

Secondary: the build also reports a `Failed to fetch one or more git submodules` warning — verify any `.gitmodules` entries in `Nexus` are accessible to the Vercel GitHub App.
